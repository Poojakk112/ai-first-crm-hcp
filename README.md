# AI-First CRM – HCP Interaction Module

An AI-first CRM tool for healthcare sales field representatives to log and
manage interactions with Healthcare Professionals (HCPs), via either a
**structured form** or a **conversational chat interface**.

## Tech Stack

- **Frontend:** React + Redux Toolkit (Vite)
- **Backend:** FastAPI (Python)
- **AI Agent Framework:** LangGraph
- **LLM:** Groq — `gemma2-9b-it` (primary), `llama-3.3-70b-versatile` available as a fallback for heavier reasoning
- **Database:** PostgreSQL / MySQL (SQLite fallback for quick local runs)
- **Font:** Google Inter

## LangGraph AI Agent & Tools

The LangGraph agent processes each interaction — whether typed into the chat
box or submitted via the structured form — through a pipeline of tools to
enrich the CRM record automatically.

| # | Tool | What it does |
|---|------|---------------|
| 1 | **Log Interaction** | Captures the raw interaction (chat text or form fields) and kicks off the enrichment pipeline. |
| 2 | **Edit Interaction** | Rewrites/cleans up the logged text into professional CRM language; also used to modify a previously saved record. |
| 3 | **Extract Entities** | Uses the LLM to pull out Doctor, Hospital/Clinic, Disease/Therapy Area, and Medicines/Products as structured JSON. |
| 4 | **Summarize** | Produces a concise 2–3 sentence CRM-ready summary of the interaction. |
| 5 | **Suggest Next Action** | Recommends 2–4 concrete follow-up actions for the rep (e.g. "Schedule follow-up meeting in 2 weeks"), shown as clickable suggestions in the UI. |

Each tool can also be triggered individually via `POST /agent/run` with an
`action` of `log`, `edit`, `extract`, `summary`, or `suggest`, or the whole
pipeline can be run with `action=all`.

## Features

### 1. Log HCP Interaction Screen
- **Structured form**: HCP Name, Interaction Type, Date/Time, Attendees,
  Topics Discussed, Materials Shared, Samples Distributed, Sentiment
  (Positive/Neutral/Negative), Outcomes, Follow-up Actions.
- **"Summarize from Voice Note" (Requires Consent)**: an AI action on the
  Topics Discussed field, gated behind an explicit consent prompt.
- **AI Suggested Follow-ups**: generated by the `suggest` tool and shown as
  one-click-to-add items under Follow-up Actions.

### 2. AI Assistant (Chat Panel)
- Log an interaction conversationally, e.g.:
  > "Met Dr. Smith, discussed Product X efficacy, positive sentiment, shared brochure"
- The agent extracts entities, summarizes, and suggests follow-ups
  automatically and saves a structured record from the free text.

### 3. History
- All interactions (from form or chat) are persisted to the database and
  retrievable via `GET /interactions`.

## How to Run

### Backend

```bash
cd Backend
python -m venv venv
source venv/bin/activate        # venv\Scripts\activate on Windows
pip install -r requirements.txt

cp .env.example .env
# then edit .env and set your GROQ_API_KEY
# (DATABASE_URL defaults to a local SQLite file if you don't have
#  Postgres/MySQL running — swap it in .env for a real deployment)

uvicorn main:app --reload
```

Backend runs at `http://127.0.0.1:8000`.

### Frontend

```bash
cd frontend
npm install
cp .env.example .env    # points VITE_API_BASE_URL at the backend
npm run dev
```

Frontend runs at `http://localhost:5173`.

## API Overview

| Method | Endpoint | Description |
|---|---|---|
| POST | `/interactions` | Log an interaction from the structured form |
| GET | `/interactions` | List all logged interactions |
| GET | `/interactions/{id}` | Get a single interaction |
| PUT | `/interactions/{id}` | Edit a logged interaction |
| DELETE | `/interactions/{id}` | Delete an interaction |
| POST | `/interactions/chat` | Log an interaction via free-text chat |
| POST | `/agent/run` | Run a single LangGraph tool on demand |

## Database

Configure `DATABASE_URL` in `Backend/.env`:

- Postgres: `postgresql+psycopg2://user:password@localhost:5432/crm_db`
- MySQL: `mysql+pymysql://user:password@localhost:3306/crm_db`
- SQLite (local/dev, no server needed): `sqlite:///crm.db`

## Conclusion

This project demonstrates an AI-first CRM system using LangGraph and Groq
